# Wolf (of Wallstreet) - AI-based Investing Advisor & Asset Monitoring System

The project aims to provide an out-of-the-box solution for tracking investing portfolio value as well as particular assets
with different AI-based capabilities providing analytic view into existing financial data. The main feature is the investing advisor system meant to deliver recommendations on given instruments (mostly stocks) with elaborate reasoning behind them based on factors such as **market price, financial health metrics and statements or news**. Moreover the system provides insight into real-time data itself with charts and graphical representations.

## To run the UI
```sh
uv sync
uv run streamlit run app/app.py   
```
